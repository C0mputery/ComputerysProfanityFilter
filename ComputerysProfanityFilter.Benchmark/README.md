This project compares ComputerysProfanityFilter with [`Profanity.Detector` 0.1.8](https://github.com/stephenhaunts/ProfanityDetector)
using all four engine/list combinations:

- ComputerysProfanityFilter with its expanded default vocabulary;
- Profanity.Detector with that same expanded vocabulary;
- ComputerysProfanityFilter with Profanity.Detector's raw default vocabulary, without word-form expansion; and
- Profanity.Detector with its raw default vocabulary.
